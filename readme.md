# 🎨 Paletizador

> Uma aplicação web desenvolvida com HTML5, CSS3 e JavaScript puro, inspirada em estética pós-impressionista (*Stilô Van Gogh*), apresentando geração dinâmica de paletas, efeitos visuais em leque e persistência de estado.

</div>

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando os pilares fundamentais do desenvolvimento Front-end:

* **HTML5:** Estrutura semântica limpa e moderna.
* **CSS3:** 
  * Estilização com **Glassmorphism** (`backdrop-filter: blur`) sobreposta a uma tela de fundo artística.
  * Efeito de **Moldura de Quadro Clássica** com sombreamento interno e externo em camadas.
  * Animação personalizada em cascata (*Leque*) utilizando `@keyframes` e `cubic-bezier`.
  * Tipografia clássica via *Google Fonts* (**Crimson Text**).
* **JavaScript (Vanilla):**
  * Manipulação avançada e dinâmica do DOM (`document.createElement`).
  * Estruturação de dados com **Arrays de Objetos**.
  * Sorteio procedural utilizando `Math.random()`.
  * Integração com a **Clipboard API** para cópia instantânea de códigos Hexadecimais.
  * Gerenciamento de estado local com **`localStorage`** para reter a paleta ativa ao atualizar a página.

---

## ✨ Funcionalidades Principais

* 🖼️ **Interface Artística com Moldura:** Um visual sofisticado simulando uma moldura de madeira entalhada emoldurando a paleta interativa.
* 🌸 **Animação em Leque:** Os blocos de cores desabrocham suavemente na tela com atrasos em cascata a cada nova geração.
* 📋 **Copiado com 1 Clique:** Clique em qualquer bloco de cor para copiar o código Hex para a área de transferência com um aviso visual (*Toast*).
* 💾 **Persistência de Estado (`localStorage`):** Mantém a sua paleta favorita ativa mesmo se a página for recarregada.
